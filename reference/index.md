# Package index

## Financial calculations

Functions and data for financial calculations

- [`tax_parameters`](tax_parameters.md) : Key income tax parameters for
  the UK.
- [`liability_tax()`](liability_tax.md) : Calculate UK income and/or
  National Insurance taxes
- [`probability_ruin()`](probability_ruin.md) : Calculate the
  probability of retirement ruin
- [`probability_ruin_rate()`](probability_ruin_rate.md) : Calculate the
  spend rate for a given probability of retirement ruin
- [`rate_annuity()`](rate_annuity.md) : Get the latest annuity rates for
  the UK
